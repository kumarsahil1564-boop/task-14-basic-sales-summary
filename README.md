# Task 14 – Basic Sales Summary

## 📌 Project Overview

This project is part of my Data Analytics internship. The objective is to create a basic sales summary using Microsoft Excel and calculate important business metrics.

## 🎯 Objective

To calculate and analyze:

- Total Sales
- Average Sales
- Transaction Count

## 🛠️ Tools Used

- Microsoft Excel
- Excel Formulas

## 📊 Key Performance Indicators (KPIs)

### 1. Total Sales
Calculates the total revenue generated from all sales transactions.

Formula:
`=SUM(Sales_Data!F2:F11)`

### 2. Average Sales
Calculates the average sales value per transaction.

Formula:
`=AVERAGE(Sales_Data!F2:F11)`

### 3. Transaction Count
Counts the total number of sales transactions.

Formula:
`=COUNTA(Sales_Data!A2:A11)`

## 📁 Project Files

- `Task_14_Basic_Sales_Summary.xlsx` – Excel workbook containing sales data and summary KPIs.

The project demonstrates basic Excel data analysis skills, including data organization, formulas, KPI calculation, and business summary preparation.
